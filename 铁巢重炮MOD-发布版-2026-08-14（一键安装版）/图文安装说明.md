# IronNestFCS 修改版安装说明

安装分为两个阶段：

1. 先安装 MelonLoader 和原作者发布的 IronNestFCS。
2. 再用本项目的 `IronNestFCS.Logic.dll` 替换原版逻辑 DLL，启用自动索敌等修改版功能。

> 适用于 Demo 和正式版。宿主同时兼容游戏 1577 更新前后带冒号和不带冒号的产品名；两者安装方法相同，区别只是游戏目录不同。

## 一、开始前准备

请先确认游戏能够正常启动，然后彻底退出游戏。

需要准备：

- [MelonLoader x64](https://github.com/LavaGang/MelonLoader/releases/latest)
- [原作者 IronNestFCS 发布页](https://github.com/svr2kos2/IronNestFCS/releases)
- 本项目生成的修改版 `IronNestFCS.Logic.dll`

先从 MelonLoader 的 GitHub 发布页下载安装程序。

### 找到正确的游戏目录

在 Steam 中右键游戏，依次选择“管理”→“浏览本地文件”。正确目录中应当能看到游戏的 `.exe` 文件，例如：

- Demo：`SteamLibrary\steamapps\common\IRON NEST Heavy Turret Simulator Demo\`
- 正式版：以实际安装位置为准，找到包含游戏 `.exe` 的目录。

不要把文件放进 `steamapps\common` 的上一级目录，也不要放进名称以 `_Data` 结尾的文件夹。

## 二、安装 MelonLoader

### 方法 A：使用自动安装程序

1. 运行 `MelonLoader.Installer.exe`。
2. 选择游戏的 `.exe` 文件。
3. 选择 x64 版本并执行安装。
4. 安装完成后，游戏根目录中应出现 `version.dll` 和 `MelonLoader` 文件夹。

### 方法 B：自动安装失败时手动安装

如果安装程序一直报下载失败：

1. 关闭游戏并退出安装程序。
2. 删除这次失败安装留下的 `MelonLoader` 文件夹和 `version.dll`。不要误删游戏本体，也不必删除已经放好的 `Mods`、`UserData`、`UserLibs`。
3. 下载 [MelonLoader.x64.zip](https://github.com/LavaGang/MelonLoader/releases/latest/download/MelonLoader.x64.zip)。
4. 解压压缩包。
5. 把解压得到的 `version.dll` 和整个 `MelonLoader` 文件夹复制到游戏根目录。

“Could not establish a connection” 通常表示 MelonLoader 无法从 GitHub 下载文件，并非 IronNestFCS 本身损坏。

## 三、安装原作者版本 IronNestFCS

如果你下载的是本项目提供的“完整玩家包”，压缩包里已经包含 `Mods`、`UserData`、`UserLibs` 三个文件夹：完成 MelonLoader 安装后，直接把这三个文件夹复制到游戏根目录并同意覆盖，然后跳到“首次启动并等待依赖生成”即可。

如果你手里只有单独的修改版 `IronNestFCS.Logic.dll`，则按下面步骤先安装原作者版本：

1. 从[原作者 Releases 页面](https://github.com/svr2kos2/IronNestFCS/releases)下载最新的 `IronNestFCS_v*.zip`。
2. 解压压缩包。

3. 解压后会看到 `Mods`、`UserData`、`UserLibs` 三个文件夹。
4. 选中这三个文件夹，把它们整体复制到游戏根目录；Windows 提示合并或替换时选择同意。

## 四、首次启动并等待依赖生成

1. 启动游戏。
2. 第一次启动时会出现 MelonLoader 黑色控制台，并自动生成 IL2CPP 依赖；这一步可能需要几分钟。
3. 不要提前关闭控制台或游戏。控制台出现下载 Cpp2IL、UnityDependencies 等内容属于正常现象。

首次启动时，MelonLoader 会从 GitHub 下载 Cpp2IL 和 UnityDependencies。网络无法访问 GitHub 时，安装往往会停在这里。

进入关卡后，如果左上角出现 IronNest FCS 状态面板，说明原作者版本已经加载成功。

## 五、替换为自动索敌修改版

> 必须先完成上面的原作者版本安装。修改版逻辑 DLL 不能单独代替 MelonLoader、宿主 DLL 和契约 DLL。

1. 完全退出游戏。
2. 打开游戏目录下的 `UserData\IronNestFCS\`。
3. 如需备份，把原来的 `IronNestFCS.Logic.dll` 复制到游戏目录之外保存。
4. 把本项目的修改版 `IronNestFCS.Logic.dll` 复制到该目录，并确认替换原文件。
5. 文件名必须保持为 `IronNestFCS.Logic.dll`。如果下载到的是旧名称 `IronNestFCS.Logic.AutoTarget.dll`，请先把它重命名为 `IronNestFCS.Logic.dll`。

再次启动游戏，左上角面板出现自动索敌、已发现目标等项目，就表示自动索敌修改版已经加载。

如果游戏已在运行，也可以在替换逻辑 DLL 后按 **F9** 热重载；首次安装或排查故障时，建议完整重启游戏。

## 六、安装完成后的目录结构

```text
游戏根目录\
├─ 游戏.exe
├─ version.dll
├─ MelonLoader\
├─ Mods\
│  └─ IronNestFCS.dll
├─ UserLibs\
│  └─ IronNestFCS.Abstractions.dll
└─ UserData\
   └─ IronNestFCS\
      └─ IronNestFCS.Logic.dll    ← 修改版文件
```

## 七、一键卸载

1. 完全退出游戏。
2. 双击发布包中的 `一键卸载.cmd`。
3. 确认游戏目录，然后点击“开始卸载”。

卸载器只移除 IronNestFCS 的宿主、契约、逻辑 DLL 和安装日志。MelonLoader、其他 Mod、游戏文件以及 `IronNestFCS_Backups` 安装备份均会保留。

## 八、常见问题

### 1. RemoteAPI 连接失败或 UnityDependencies 下载失败

这通常是 MelonLoader 无法从 GitHub 下载依赖。可以手动补文件：

1. 下载 [Managed.zip](https://github.com/LavaGang/MelonLoader.UnityDependencies/releases/download/6000.3.9/Managed.zip)。
2. 重命名为 `UnityDependencies_6000.3.9.zip`。
3. **不要解压**。
4. 把压缩包放入：

```text
游戏根目录\MelonLoader\Dependencies\Il2CppAssemblyGenerator\
```

### 2. 不能加载 Cpp2IL

1. 删除：

```text
游戏根目录\MelonLoader\Dependencies\Il2CppAssemblyGenerator\Cpp2IL\Cpp2IL.exe
```

2. 下载 [Cpp2IL-2022.1.0-pre-release.21-Windows.exe](https://github.com/SamboyCoding/Cpp2IL/releases/download/2022.1.0-pre-release.21/Cpp2IL-2022.1.0-pre-release.21-Windows.exe)。
3. 把下载文件重命名为 `Cpp2IL.exe`。
4. 放入：

```text
游戏根目录\MelonLoader\Dependencies\Il2CppAssemblyGenerator\Cpp2IL\
```

MelonLoader 0.7.3 还需要同版本的 `Cpp2IL.Plugin.StrippedCodeRegSupport.dll`，放入：

```text
游戏根目录\MelonLoader\Dependencies\Il2CppAssemblyGenerator\Cpp2IL\Plugins\
```

只有 `Cpp2IL.exe` 而没有该插件时，MelonLoader 仍会尝试从 GitHub 下载插件，并可能显示 Cpp2IL 安装失败。新版一键安装包会自动补齐这两个文件。

### 3. 自动安装程序反复报错

使用上文“方法 B”手动安装 MelonLoader。很多此类报错的根本原因是安装程序无法连接 GitHub。

### 4. 游戏能启动，但没有 FCS 面板

依次检查：

- `Mods\IronNestFCS.dll` 是否存在。
- `UserLibs\IronNestFCS.Abstractions.dll` 是否存在。
- `UserData\IronNestFCS\IronNestFCS.Logic.dll` 是否存在且文件名正确。
- 是否装了 x64 版 MelonLoader。
- MelonLoader 控制台是否出现红色报错。
- 进入包含炮塔和地图桌的关卡后，按一次 **F9** 重新绑定并热重载。

### 5. Demo 能用，正式版不能用，或反过来

两版可以采用同样的安装结构，但必须把文件放进当前实际运行的那个游戏目录。最常见的问题是把修改版 DLL 复制到了 Demo 目录，却启动了正式版，或者反过来。
