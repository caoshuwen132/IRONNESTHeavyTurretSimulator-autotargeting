# IronNestFCS 修改版功能说明

本文说明当前修改版已经实现的功能、自动决策规则和已知限制。宿主同时识别游戏 1577 更新前后带冒号和不带冒号的产品名，兼容《Iron Nest: Heavy Turret Simulator》正式版与 Demo。

## 安装与热重载

逻辑 DLL 放置位置：

- 正式版：`<游戏目录>\UserData\IronNestFCS\IronNestFCS.Logic.dll`
- Demo：`<Demo 目录>\UserData\IronNestFCS\IronNestFCS.Logic.dll`

游戏运行时按 `F9` 可热重载逻辑 DLL，无需重新启动游戏。热重载后需要重新开启“自动索敌”和“自动开火”。

## 使用模式

- `自动索敌`：每 2 秒扫描一次任务系统中的存活敌军，自动选择目标、弹种和落点；最多同时安排两项任务。
- `只读桌面`：默认开启且按钮显示绿色；开启后，新发现及临时替补目标只会从测绘台上当前露出有效图标的敌军中选择。关闭后恢复完整实体扫描。
- 已经进入等待队列或炮管处理流程的目标不受后续图标显隐影响，即使图标消失也会照常完成发射。
- 两个任务槽均被占用时暂停完整地图扫描；命中结算仍正常运行，任一槽位释放后下一轮立即恢复索敌，减少无效后台计算。
- `自动开火`：开启时绕过实体弹道计算器和左下角计算卡片，直接使用游戏炮管内部弹道模型解算并请求击发。
- 关闭 `自动开火`：仍保留原游戏的计算卡片、确认台和手动击发流程。
- 手动 T1～T4：地图指针最下方尖角是固定落点；匹配到的真实目标 ID 只用于防止重复攻击，不会把落点吸附回图标中心。

## 自动索敌与目标识别

- 直接读取 `FireMission` 的完整实体注册表和 `EntityLocation`，不依赖玩家放置的 T1～T4 标记。
- 可识别炮兵、炮兵指挥官（FDC）、防空火炮、补给仓、机械化、侦察、舰船、步兵和其它目标。
- 读取目标生命值、装甲、状态、弹药免疫、星级、奖励和运行时图标。
- 关闭 `只读桌面` 后，可发现任务系统中存在但地图未显示的 `Hidden` 敌军，并使用其内部坐标射击；面板标记为 `[HID]`。
- 航迹、舰船等嵌套目标会从完整实体表中读取，不局限于地图根节点的第一层图标。
- 移动目标取得稳定速度样本后可以进入攻击队列；面板标记为 `[MOV]`。

## 攻击优先级

正常情况下按以下顺序选择目标：

| 顺序 | 类别 | 规则 |
| --- | --- | --- |
| 1 | 炮兵 | 与指挥官同时存在时从炮兵开始交替攻击 |
| 2 | 指挥官 | 与炮兵组成交替序列 |
| 3 | 防空火炮 | 高于其它支援目标 |
| 4 | 补给仓 | 实测会给分，可参与低积分恢复 |
| 5 | 机械化 | 实测不给分，不参与低积分恢复 |
| 6 | 侦察 | 实测会给分，可参与低积分恢复 |
| 7 | 其它目标 | 比较群伤覆盖、已知奖励、星级和距离 |
| 8 | 步兵 | 始终排在最后 |

补充规则：

- 积分不高于约 56 点时，补给仓或侦察目标可临时穿插到最前面，帮助恢复积分。
- 机械化和步兵不作为恢复积分目标。
- 炮兵或指挥官单独存在时不会推进交替游标；两类重新同时出现时仍从炮兵开始。
- 补给、机械化和侦察使用独立层级，不会因星级跨越彼此的类别顺序。
- 积分恢复目标内优先比较星级，其次群伤覆盖数、已知奖励和距离。
- 其它同类目标优先比较群伤覆盖数，其次已知奖励、星级和距离。

## 自动选弹

- 启动时读取当前关卡实际加载的炮弹定义，包括伤害、爆炸半径、效果图和购买价格。
- 启动时逐项审计当前正式版的 20 种弹药，检查购买卡、价格、游戏炮弹定义、购买控件绑定和自动杀伤资格；审计本身不会购买弹药或消耗积分。
- PCLM 在购买卡上使用 `PCLM`，正式版炮弹定义和弹仓内部仍可能使用旧拼写 `PLCM`。系统会统一识别为 `PCLM`，避免找不到购买卡、重复购买或装填失败。
- `Damage` 数值不是“一击必杀”的充分条件。自动系统还会检查弹药效果图，只有直接对地图实体造成伤害、且不依赖条件分支、等待、计时、状态改变或驱散移动的弹药，才可作为自动杀伤弹。
- `PHGN` 需要目标先处于压制状态，否则只会驱散；`CYAN`、`SMK` 等特殊效果弹也不会参与自动选弹，但仍可手动使用。
- 游戏以后新增的条件型、延迟型或状态型弹药会按效果节点自动排除，不必只依赖弹种名称。
- 地下目标、装甲目标或只对 AP 有效的目标强制使用 AP，不沿用面板原弹种。
- `Fortification` 仅表示固定设施，不等于地下。医院、总站等没有地下标识、装甲为 0 且不免疫普通弹的设施不会误用 AP。
- 舰船装甲表示舰体防护，不会被误标为地下；需要时仍按免疫和装甲规则使用 AP。
- 单个非 AP 目标如果可被低价训练弹 `DRIL` 直接摧毁，会自动改用 `DRIL` 节省积分。自动索敌先验证弹药能否直接致死，`STAR`、`SMK`、`PHGN`、`TEAR` 等功能弹即使价格更低，也不会因价格而被自动保留。
- `HCHE` 只有预计爆炸范围内至少有 3 个能被其直接摧毁的敌军时才允许自动选择；单目标、双目标和普通弹兜底均排除 `HCHE`，即使控制台当前弹种就是 `HCHE` 也不能绕过该门槛。
- 目标免疫当前弹种时，该弹种不会进入有效方案。

## 范围弹与群伤落点

- 普通范围弹至少可一次摧毁两个目标时才参与比较；`HCHE` 单独要求至少摧毁三个目标。
- 范围弹成本高于逐个使用当前有效弹种的总成本时，不会自动采用该范围弹。
- 落点候选包括目标位置、目标两两中点、目标圆交点和群体中心；选择覆盖数量最多、容错余量更大的地图内位置。
- 同一种炮弹的有效目标和落点候选每轮只计算一次，并供所有可能的主目标复用；友军位置也只读取一次，减少密集目标下的瞬时卡顿。
- 爆炸半径内存在友军时，该落点会被排除。
- 同一发预计覆盖的其它敌军会暂时锁定，避免左右炮重复攻击同一组目标。
- 移动编组的群伤中心会在开火前持续重算，不再固定在接单时的旧坐标。
- 移动编组每轮重算共用一份友军位置快照，不再对每个候选落点重复遍历整张地图。
- 实时重算会考虑主目标和附带目标的最新位置、实测速度及炮弹飞行时间。编组散开后会降低预计覆盖数；必要时退化为只保证命中主目标。

## 移动目标与行进间射击

- 所有移动敌军均可参与追踪，包括被毒气或烟幕驱散的普通单位。
- 游戏的 `Moving` 标志提前复位时，仍会根据连续位置样本的实测速度判断目标是否在移动。
- 移动目标至少取得两个方向和速度稳定的样本后才进入队列。
- 装填、仰角调整和炮塔旋转期间持续更新目标位置；开火前每 0.2 秒重新计算方向、距离、仰角和飞行提前量。
- 方向和仰角连续三个更新周期进入误差范围后才允许击发。
- 移动目标预测距离最多 2 千米，异常速度或地图外落点会被拒绝。
- 玩家火炮移动时使用 `TurretController.turretBase` 的真实炮位解算，不依赖桌面炮位标记是否由玩家正确摆放。
- 测绘台上的“铁巢”炮位标志每 0.2 秒通过游戏原生坐标接口自动同步到真实炮位；玩家手动放错后也会被自动校正。
- 若当前场景没有炮位标志，仅跳过标志显示同步，不会阻止自动索敌和真实炮位解算。
- 移动炮位至少取得两个稳定样本后才进行预测，炮位预测距离最多 5 千米。
- 游戏移动状态结束后仍检查实测炮位速度，连续三个静止样本后才按停车处理。
- 如果游戏原生 `CanFire` 禁止行进中击发，系统保持准备状态，待允许开火后重新校正并立即发射。
- 已装填炮弹无法命中原目标时，优先改选射程内目标；没有合适目标时选择经当前弹种、装药真实弹道校验的地图内安全位置空放，释放炮管。

## 双炮并行调度

- 两管炮可并行购弹、装填、调整各自仰角和准备下一项任务。
- 共享炮塔旋转与装填、升仰角同时进行，减少串行等待。
- 只有当前最早的候选任务可以预转向；后续任务不会抢夺方向控制，避免炮塔在新旧目标之间来回摆动。
- 仰角先就绪的炮管取得更高的最终方向优先级；发射后立即把共享炮塔控制权交给另一管。
- 上一发尚未完成落点结算时，下一发已经可以购买弹药并开始准备。
- 自动流程不会强制退弹。`CanFire=false`、目标失效或暂时无解时保留膛内炮弹，持续实时重选目标或安全空放；装填推杆暂不可用时等待原生机构恢复并重试。
- 热重载或任务交接后发现炮膛内存在不属于当前任务的遗留弹药时，先为该弹寻找经过真实弹道验证的地图内安全空放点并正常击发；机械复位后继续原目标，不释放目标预约，也不把空放计作目标攻击。

## 积分、购买与装药

- 期望积分下限为 50 点；面板显示 `RP Mode` 和当前积分。
- 购弹时允许积分暂时低于 50，但自动任务至少保留 1 点，不会仅因低于 50 而整体停止。
- 两管炮已安排但尚未购买的弹药会共同计入预算，避免重复花费同一笔积分。
- 系统会结合弹药成本和预计命中目标数选择更划算的方案。
- 购弹后读取对应炮管的真实弹仓确认结果；卡片入槽或购买按钮偶发未响应时最多重试三次。三次仍未进入弹仓则取消该任务，不会带着未买到的弹药继续装填并卡住炮管。
- 两炮共用装药余量少于 10 时，每 5 秒尝试购买一次装药卡，直到恢复到阈值；积分保护仍然生效。
- 面板与日志显示当前积分、最近一次奖励及目标读取到的奖励信息。

## 防止重复攻击与命中追踪

- 从任务入队到炮弹结算期间，主目标和预计群伤目标保持锁定。
- 已确认摧毁的目标在本局中永久排除。
- 未命中或任务取消后等待 20 秒才允许重新选择。
- 一发炮弹 180 秒仍没有结果时解除锁定。
- 隐藏目标优先读取实体生命值和 `Destroyed` 状态，不完全依赖正式版可能失真的命中/未命中计数。
- 热重载前已经在空中的炮弹单独处理，避免旧结果错误释放热重载后的新任务。

## 阀门维护与状态面板

- 自动扫描当前场景中的压力阀门，发现松动后调用游戏原生修复动作拧紧。
- 面板显示检测到的阀门数、松动数和累计自动修复数。
- 左右炮分别显示目标类别、弹种、任务阶段、方向和距离。
- 队列目标可显示 `[ART]`、`[FDC]`、`[AA]`、`[SUP]`、`[MECH]`、`[REC]`、`[INF]`、`[HID]`、`[MOV]` 等标记。
- `AOE×数量` 表示当前预计由一发覆盖的目标数；移动编组散开后该数值会动态下降。

## 已知限制

- 移动预测假定目标在炮弹飞行期间大致延续最近的方向和速度；突然转向、急停或任务脚本瞬移仍可能造成未命中。
- 游戏自身可能拒绝某些移动状态下的击发，Mod 不会绕过游戏内部安全条件。
- 非隐藏目标的全局命中/未命中统计在部分正式版任务中可能与实际奖励或摧毁状态不同；日志会保留射击与奖励记录供进一步校正。
- 特殊效果弹保留给手动使用，自动系统以“可靠直接摧毁”为优先，不追求使用所有已购买弹种。

## 主要源代码

- `IronNestFCS.Logic/FSC.cs`：自动索敌、优先级、积分预算、任务调度、群伤规划、防重复攻击和阀门维护。
- `IronNestFCS.Logic/FCS/MapTable.cs`：实体坐标、实时炮位、移动预测、动态群伤落点、目标类别、地下与弹药免疫判断。
- `IronNestFCS.Logic/FCS/PurchaseDeck.cs`：弹药定义、效果图、伤害半径和购买价格读取。
- `IronNestFCS.Logic/FCS/GunSystem.cs`：炮管装填、仰角控制、飞行时间、提前准备、击发和原生机构恢复等待。
- `IronNestFCS.Logic/RequisitionPointsMonitor.cs`：积分与奖励监视。
- `IronNestFCS.Logic/FcsWindow.cs`：游戏内状态面板。
# 局内自由视角

- `F10`：开启或关闭自由视角，`Esc` 也可以退出。
- 鼠标：转动视角。
- `W/A/S/D`：前后左右移动。
- `空格 / C`：上升 / 下降。
- `Shift`：加速，`Ctrl`：慢速精细移动。
- `F11`：独立开启或关闭碰撞箱显示。普通碰撞为青绿色，触发区域为黄色；正常视角和自由视角下均可使用。
- 自由视角开启时暂停玩家自身的操作输入，避免观察过程中误触室内设备；自动索敌与火炮任务仍会继续。
- 左上角火控状态面板已汉化；保持原英文界面的 24 像素行高和 4 像素行距，弹药代号保留原名。
