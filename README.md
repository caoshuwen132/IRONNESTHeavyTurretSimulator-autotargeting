# IronNestFCS 修改版功能说明

本文记录在原项目基础上增加和调整的功能。当前 DLL 同时面向游戏 Demo 与正式版。

## 安装位置

正式版逻辑 DLL：

`E:\Games\Iron Nest Heavy Turret Simulator\UserData\IronNestFCS\IronNestFCS.Logic.dll`

Demo 版逻辑 DLL：

`E:\SteamLibrary\steamapps\common\IRON NEST Heavy Turret Simulator Demo\UserData\IronNestFCS\IronNestFCS.Logic.dll`

游戏运行时按 `F9` 可热重载逻辑 DLL。热重载后需要重新开启 `Auto Target` 和 `Auto Fire`。

## 自动索敌与攻击顺序

- 每 2 秒扫描一次可攻击目标，同时最多安排两项射击任务。
- 炮兵与指挥官是最高战术优先级；两者同时存在时，从炮兵开始交替攻击。
- 其余目标按补给仓、机械化、侦察、普通目标、步兵的范围参与排序；步兵始终放在最后。
- 同类目标优先选择已知奖励较高者，其次星级较高者，最后选择距离较近者。
- 积分接近目标下限时，优先穿插已确认会给分的补给仓或侦察目标；机械化和步兵不作为恢复积分目标。

## 积分与购弹

- 期望积分下限为 50 点。
- 购弹时允许积分临时低于 50 点，但至少保留 1 点，自动系统不会因为低于 50 点而整体停止。
- 自动任务会把已经安排但尚未购买的炮弹计入预算，避免两管炮重复花费同一笔积分。
- 支持在上一发尚未完全结算时为下一项任务准备或购买弹药。
- 面板与日志会显示当前积分、最近一次奖励和目标读取到的奖励信息。

## 目标识别与弹种

- 可识别炮兵、指挥官、补给仓、机械化、侦察和步兵，并读取目标星级。
- 通过角色、名称、图标、附加状态图标以及游戏自身的弹药免疫信息识别地下目标。
- 地下目标或仅对 AP 有效的目标会强制使用 AP 弹，不沿用面板上原先选择的 HE 等弹种。
- 地图坐标只使用地图平面的 X/Y 位置计算，避免 UI 层级的 Z 轴偏移把射击位置算到地图外。

## 防止重复攻击

- 手动点击 T1～T4 后，会按角度和距离匹配对应的真实目标 ID。
- 从任务入队到炮弹落地期间，目标始终保持锁定，后续炮管不会再次选择同一目标。
- 命中并确认摧毁的目标会在本局中永久排除。
- 未命中或任务取消后，等待 20 秒才允许重新选择；180 秒仍无结果时解除锁定。
- 热重载前已经在空中的炮弹会单独处理，避免它的命中结果错误释放热重载后的新目标。

## 炮塔维护与兼容性

- 自动监视当前场景中的压力阀门，发现松动后调用游戏原生修复动作拧紧。
- 状态面板显示检测到的阀门数、松动数和自动修复数。
- 兼容 Demo 与正式版在目标名称、实体信息及程序集结构方面的差异。

## 主要源代码

- `IronNestFCS.Logic/FSC.cs`：自动索敌、优先级、积分预算、任务调度、防重复攻击和阀门维护。
- `IronNestFCS.Logic/FCS/MapTable.cs`：地图坐标、目标类别、星级、地下标识、奖励信息和手动目标匹配。
- `IronNestFCS.Logic/FCS/GunSystem.cs`：炮管装填、弹种选择、提前准备及击发流程。
- `IronNestFCS.Logic/RequisitionPointsMonitor.cs`：积分与奖励监视。
- `IronNestFCS.Logic/FcsWindow.cs`：游戏内状态面板。
