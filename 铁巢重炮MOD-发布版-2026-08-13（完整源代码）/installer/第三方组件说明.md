# 第三方离线组件说明

一键安装包为了避免 MelonLoader 从 GitHub 下载失败，附带以下未经修改的官方文件：

- `MelonLoader.x64.zip`：[LavaGang/MelonLoader](https://github.com/LavaGang/MelonLoader/releases)
- `UnityDependencies_6000.3.9.zip`：原文件名为 `Managed.zip`，来自 [LavaGang/MelonLoader.UnityDependencies](https://github.com/LavaGang/MelonLoader.UnityDependencies/releases/tag/6000.3.9)
- `Cpp2IL.exe`：原文件名为 `Cpp2IL-2022.1.0-pre-release.21-Windows.exe`，来自 [SamboyCoding/Cpp2IL](https://github.com/SamboyCoding/Cpp2IL/releases/tag/2022.1.0-pre-release.21)
- `Cpp2IL.Plugin.StrippedCodeRegSupport.dll`：与 Cpp2IL `.21` 配套的 stripped code registration 支持插件，来自同一版本的 Cpp2IL 插件发布文件。

这些组件分别遵循各自上游项目的许可证。本项目不修改这些文件，只在安装时把它们放入 MelonLoader 所需目录。Cpp2IL 主程序和配套插件必须同时存在；只有 `Cpp2IL.exe` 时，MelonLoader 仍可能尝试联网下载插件并提示 Cpp2IL 安装失败。
